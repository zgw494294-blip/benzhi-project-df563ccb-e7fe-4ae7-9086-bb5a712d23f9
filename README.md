# StallSettle

StallSettle 是面向社区市集与合作商店的寄售工作台。它通过浏览器完成寄售单建档、商品上架、逐笔销售登记和最终结算，并使用整数分、幂等键、版本号与本地 JSON 账本保存可追溯的结算凭据。

## 业务能力

草稿阶段可以修改摊主与佣金率，维护唯一商品编号、整数库存和精确到分的单价。上架后，工作台按幂等键逐笔登记销售，并展示实时销售额、售出进度、待退数量和预计应付金额。结算会锁定逐商品销售与退还明细，刷新页面或重启进程后仍可从本地账本读取同一份凭据。

账本索引支持按摊主、寄售单编号或商品搜索，也可以按业务状态筛选和排序。所有写操作都携带寄售单版本，持久化成功后才替换进程内状态。

## 构建与运行

项目固定使用 Go 1.22.0。构建：

```text
go build ./cmd/stallsettle
```

启动服务：

```text
go run ./cmd/stallsettle
```

服务默认监听 `:8080`，浏览器访问 `http://localhost:8080/`。可以使用 `-addr` 调整地址，使用 `-ledger` 指定本地账本路径。

## 测试

运行全部测试：

```text
go test ./...
```

运行完整流程自检：

```text
go run ./cmd/stallsettle -smoke
```
